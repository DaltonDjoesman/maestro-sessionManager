# Maestro v0.1.0

First public release of **Maestro** — a Linux session launcher for personal / portfolio use.

## What it does

- Store work sessions as local JSON profiles (apps + browser URLs)
- Capture running windows into a draft profile (Captura assistant)
- Activate a profile in one click and show a step timeline overlay
- Preview / dry-run activation without spawning processes

## Supported platform

- Built and tested on **Pop!_OS** / Ubuntu-class Linux (Cosmic preferred for workspace-aware capture)
- Installers: `.deb` and AppImage when both build successfully on the release host

## Known limits

- **Launcher only** — not a window manager; does not place windows or tear down / kill launched apps
- Default UI locale is **pt-PT** (English i18n is a scaffold only; no locale switcher yet)
- Capture workspace grouping depends on the compositor; unsupported Wayland desktops omit workspace headings instead of inventing fake ones
